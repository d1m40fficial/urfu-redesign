# УрФУ — редизайн портала. Концепция «Меридиан»

## 1. Задача

Действующий портал `urfu.ru` (TYPO3, ~2017) перегружен: три пересекающиеся
навигации, промо-карусель из девяти баннеров на первом экране, 26 категорий
новостей, отдельная «версия для слабовидящих». Посетитель не понимает, с чего
начать. Цель — полностью пересобрать структуру, навигацию и визуальный язык,
обновив логотип, и показать результат интерактивным прототипом.

## 2. Идея: «Меридиан — точка отсчёта»

УрФУ стоит на границе Европы и Азии. Меридиан — это линия отсчёта, ориентир.
Интерфейс делает то же самое: за пять секунд даёт ответ «сюда ли мне?» и
проводит к одной понятной цели.

Три принципа (каждый называет, чем платим):

1. **Один экран — один ответ.** Экран ведёт к одному главному решению,
   вторичные пути отступают. *Платим:* промо-плотностью — убираем 9 баннеров и
   26 категорий.
2. **Навигация по намерению, а не по оргструктуре.** Посетитель выбирает, что
   хочет сделать, а не какой отдел за это отвечает. *Платим:* удобством
   внутренних подразделений — убираем дублирование «8 разделов × 14 подпунктов».
3. **Система важнее украшения.** Точность, линии, читаемость данных; акцент —
   сигнал. *Платим:* выразительностью — меняем визуальный фейерверк на ясность и
   доступность.
4. **Доступность — основа, а не режим.** WCAG 2.2 AA встроена в основной сайт;
   отдельной «версии для слабовидящих» нет.

## 3. Новая информационная архитектура

### Верхнее меню (5 разделов по намерению)

| Раздел | Что внутри | Для кого |
|--------|-----------|----------|
| **Поступить** | Программы, шаги приёма, сроки, стоимость, общежитие, ДОД, иностранным абитуриентам | Абитуриенты, школы |
| **Образование** | Уровни (базовое высшее, специализированное, магистратура, аспирантура, ДПО), институты, онлайн-курсы | Студенты, абитуриенты |
| **Наука** | Исследования, лаборатории, публикации, научно-популярное | Студенты, исследователи, партнёры |
| **Студентам** | Расписание, БРС-рейтинг, стипендии, документы, сервисы, поддержка | Текущие студенты |
| **Университет** | Об УрФУ, кампус, жизнь, цифры, новости, события, контакты | Все, пресса |

Служебный кластер (справа): **Поиск**, **RU/EN**, **Личный кабинет**,
**Быстрые действия**. Никаких двух меню и карусели-дублёра.

### Что убрали
- Карусель «быстрых туров» из 8 вкладок (дублировала меню).
- Отдельное 14-пунктовое подменю (дублировало меню).
- 9 промо-слайдов → один осмысленный первый экран.
- 26 категорий новостей → единая лента «Пульс» с ≤8 фильтрами.
- Отдельную версию для слабовидящих → встроенная доступность.

### Что добавили
- **Маршрутизатор задач** на первом экране: «Я абитуриент / студент / сотрудник
  / партнёр / пресса» → ведёт в готовый маршрут.
- **Поиск программы** прямо в первом экране — главное действие абитуриента.
- **«УрФУ в цифрах»** как отдельный смысловой блок, а не четыре баннера.
- **Единая лента «Пульс»** — новости и события вместе, с фильтрами.
- **Липкая навигация по шагам приёма** на странице «Поступить».

## 4. Визуальный язык

- **Палитра.** Глубокий академический синий (OKLCH-шкала) + один акцент —
  янтарный «пункт отсчёта» (≤5% площади). Тонированные нейтрали вместо чистого
  серого.
- **Типографика.** Дисплей — **Onest** (800), текст — **Golos Text**, цифры —
  **JetBrains Mono**. Все три с кириллицей.
- **Форма.** Один жанр поверхности: ленты с волосяной линией. Секции
  разделяются линией, инверсией плашки или сменой фона — не одинаковым отступом.
- **Мотив «меридиан».** Тонкая вертикальная линия-ориентир, выноски-coordinates
  в моноширинном шрифте, янтарная точка.
- **Motion.** Токены 120/200/320ms, только transform/opacity, полный
  `prefers-reduced-motion`.

## 5. Логотип

Знак-«меридиан»: скруглённый квадрат глубокого синего, внутри — монограмма «У»
(УрФУ / Урал), чья правая ножка завершается янтарной точкой отсчёта. Знак
работает отдельно (аватар, favicon) и в горизонтальном локапе со словом «УрФУ»
и полным названием. Есть инверсная версия для тёмных фонов.

## 7. Технология

Чистый HTML/CSS/JS без сборки — идеально для GitHub Pages. Один общий стилевой
файл (`assets/css/urfu.css`) владеет токенами и компонентами; страницы добавляют
только разметку. Прогрессивное улучшение: базовый контент доступен без JS.

## 8. Демонстрационные данные

Все числа, названия программ, новости и события — **образец** и помечены как
таковые. Реальные данные, фото и юридические тексты — нерешённые решения
(см. `DESIGN.md` §7) и в прототип не подставляются.
